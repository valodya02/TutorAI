# План работ TutorAI

## Текущее состояние

Рабочий MVP на FastAPI + vanilla JS: генерация плана/модулей/теории через Groq LLM, режим курса по PDF, сохранение курсов в JSON. Проект личный, однопользовательский; auth, квоты и публичное развёртывание не являются целями. Тестов, линтеров, Docker и CI нет. Зависимости зафиксированы в `requirements.txt`.
