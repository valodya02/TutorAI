# План работ TutorAI

## Текущее состояние

Рабочий MVP на FastAPI + vanilla JS: генерация плана/модулей/теории через Groq, режим курса по PDF, сохранение курсов в JSON. Проект рассчитан на локальное личное использование одним пользователем; auth, квоты и публичное развёртывание не являются целями. Тестов, линтеров, Docker и CI нет. Зависимости описаны в `requirements.txt`; секрет `.env` исключён из Git, runtime-данные и байткод исключены из индекса.
